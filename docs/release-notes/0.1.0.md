# genomics-mcp 0.1.0

First release. An MCP server (stdio, or authenticated loopback Streamable HTTP) for bounded genomic data and versioned reference evidence, run on your own machine. Research use only.

## Included

- 23 tools: discovery (EGA, ENA, ENCODE, GEO, NCBI Datasets), transfers, genomics readers (BAM/CRAM, VCF/BCF, FASTA, BED/GFF3/GTF, bigWig/bigBed on local disk, HTTPS or S3), composition (`inspect_locus`, `compare_samples`), and reference evidence (HGNC, Ensembl, ClinVar, gnomAD, UniProt, Open Targets, optional AlphaGenome Atlas).
- Artifacts: container `ghcr.io/rewire-bio/genomics-mcp:0.1.0` (linux/amd64), wheel and sdist, `requirements.lock.txt`, `build-constraints.txt`, an MCPB bundle (Node launcher for the digest-pinned container), `image.json` and `SHA256SUMS`.

## Evidence

- Reader results match samtools/bcftools 1.24 on synthetic golden data. CRAM with correct, wrong, missing and embedded references was checked. Local, HTTP-range and local MinIO results are identical. Dummy ambient AWS credentials are shown to be unused. Real MCP round trips run over stdio and authenticated HTTP. See docs/data-access.md.
- Five clean-install demonstrations with live data ran on 2026-09-25: an EGA public-test BAM region (91 records received, 42 overlapping), an ENA DQ285577.1 FASTA artifact (756 bytes, 614 bases), an ENCODE ENCFF792QDS bigWig mean over chr1:[1000000,1001000) (26.361254017233847, range reads only), NC_000007.14 REF check plus ClinVar VCV000013961.143 with germline, somatic and oncogenicity classifications kept separate, and a synthetic BAM on local MinIO. See docs/demos.md.

## Limits

- Tested on macOS arm64 and Linux x86_64 (CI). The container is linux/amd64 only. Linux arm64 and Intel macOS are untested. Windows only through WSL2 or the container.
- Python installs build pyBigWig from source (compiler, libcurl and zlib headers), because the published Linux wheel cannot read remote files. There is no compiler-free native install.
- Header build labels such as `AS:GRCh38` are reported as labels, not as proof of an exact assembly accession.
- EGA controlled data needs your own EGA account. gnomAD's public API allows about 10 requests/minute. COSMIC is not included. Atlas needs your own key and is verified only offline.
- MCPB host application install flows have not been tested.
- No hosted service. No clinical interpretation, variant calling or liftover.
